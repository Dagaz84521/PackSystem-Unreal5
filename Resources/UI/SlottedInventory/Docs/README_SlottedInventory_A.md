# Slotted Inventory · 墨底旧金 · v1

本包用于用户另一台电脑上的 Slotted 背包 UI 原型。生成日期：2026-09-03。
使用内置 imagegen 生成并迭代，未修改当前项目 C++、蓝图或 .uasset。
这是一套源分辨率 PNG 美术素材，不是已经配置完成的 UE 控件。

## 重要说明

- 六张最终素材均经检查为不透明 RGB PNG，没有 Alpha 通道。这些是完整底图，不是透明描边叠加层。
- 格子的黑色内部是有意保留的背景。图标和数量应绘制在底图上方。
- Selected 也是完整底图，选中时替换当前背景，不能当透明发光层盖在物品图标上。
- 不包含物品图标、场景图片的独立资产、文字贴图或关闭按钮贴图。预览中的图标仅供风格参考。
- 箱子标题、数量和关闭符号由控件绘制，方便更改内容。
- 普通、悬停、按下、选中均保持 1254 × 1254 的统一画布；生成式编辑会带来细微纹理差别，并非像素级相同底纹的颜色变换。
- 原始分辨率用于保存美术细节，并不等于控件显示大小。这一版尚未在用户另一台电脑的 UE 项目中验证。

## 布局起点

以下数值是 1920 × 1080 设计画布下的建议值，不是固定要求：

- 单格显示尺寸：88 × 88。
- 格子间距：8。
- 玩家背包：10 格横排；底板 1000 × 128；左右内边距 24、上下内边距 20。
  计算：10 × 88 + 9 × 8 + 2 × 24 = 1000。
- 底板底部距屏幕约 28～36。
- 箱子：面板 344 × 392；九宫格总尺寸 280 × 280；左上角可放在面板内 (32, 80)。
- 箱子显示于玩家背包上方，两者不重叠。
- 关闭符号和标题放在顶部空白标题区，不要画进格子。

## 在 UE 中的使用思路

1. 只将 Textures 文件夹内的六张 PNG 导入项目；Reference 不需要导入。
2. 玩家背包底板建议使用 Draw As = Box 的九宫格拉伸，避免直接将 3:1 原图拉到约 8:1 时压扁四角。Box 会保留角区并拉伸中心和边条，切分由 Margin 决定，见 [Epic 的 FSlateBoxBrush 说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/SlateCore/FSlateBoxBrush)。
3. Hotbar 的 Margin 可先试 Left/Right = 0.06、Top/Bottom = 0.17；Brush Image Size 可先试 384 × 128。这是按本图装饰范围估计的起点，需在目标 UE 版本与 DPI 下检查，不是已经引擎验证的配置。
4. 箱子底板先按约 8:9 比例使用 Draw As = Image。它含顶部横向分隔线，不建议随意改成极宽或极高的比例。
5. 格子四张底图都按相同 88 × 88 尺寸显示。可对应 Button 的 Normal、Hovered、Pressed 背景。
6. Selected 表示持续选中状态，不等于鼠标按住状态；由现有蓝图选中逻辑切换，不会仅靠 Button 的 Pressed 样式自动保持。
7. 保持 Brush Tint 为白色，避免原图被额外染色；额外的内容边距由图标/数量的容器控制。

## 验收建议

- 玩家格子数量为 10，箱子为 9。
- 四个状态切换时控件尺寸不变，图标和数量位置不变。
- 悬停为米白，持续选中为旧金，两者可以辨别。
- 底条四角没有被直接拉伸压扁；没有白色外部留白。
- 打开箱子后，底部玩家背包仍可见，箱子不挡住它。
